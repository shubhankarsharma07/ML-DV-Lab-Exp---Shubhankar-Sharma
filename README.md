# 📊 Data Visualization & ML Lab Notebooks

Colab notebooks covering data cleaning, visualization, mapping and core machine learning in Python.

| Notebook | What it covers |
|---|---|
| `DV_Lab1_Core_Charts_Matplotlib_Seaborn` | 9 chart types on sales data |
| `DV_Lab2_Data_Cleaning_Imputation_Merging` | Merging, imputation, joins |
| `DV_Lab3_Advanced_Interactive_Plotly` | Interactive Plotly charts |
| `DV_Lab4_Geospatial_Folium_Volcano_Map` | Volcano maps with Folium |
| `ML_Data_Preprocessing_Messy_Ecommerce` | Cleaning a 50k-row messy dataset |
| `ML_Lab_Core_Algorithms_Sklearn` | 9 scikit-learn algorithms + revision sheet |

**Stack:** pandas, numpy, matplotlib, seaborn, plotly, geopandas, folium, scikit-learn

**Run:** Open a notebook in Google Colab, upload the CSV it reads, and run the cells top to bottom.
